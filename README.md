# Amazon Clone

A web-based Amazon Clone project that simulates an e-commerce shopping experience. It includes product listing, cart functionality, checkout pages, and order tracking UI — built using HTML, CSS, and JavaScript.

## Features

- Product Listing Page: Displays a grid of products  
- Cart Functionality: Add/remove items, update quantities  
- Checkout Page: Simulated checkout flow  
- Order Tracking: Track order status 
- Responsive Design: Works on desktop and mobile  
  
## Tech Stack

- Frontend: HTML, CSS, JavaScript  
- Scripts: Custom JS for cart and navigation  
- Assets: Images, CSS, and JavaScript in structured folders
